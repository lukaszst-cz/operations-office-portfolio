JAK TO DZIAŁA

Dziecko nie potrzebuje panelu administracyjnego.
Rodzic nie potrzebuje kolejnej listy do ręcznego pilnowania.

01

Dziecko ma swój prosty ekran

Dzisiaj, rutyny, szkoła, czytanie, aktywność, szybka notatka, nastrój i wspólne sprawy.

02

Rodzic widzi szerszy obraz

Pełne statusy, terminy, prośby o pomoc, administrację szkolną i prywatne zaplecze.

03

Wspólne dane synchronizują się logicznie

Ta sama sprawa nie jest kopiowana. Zmiana statusu dotyczy jednego rekordu, tylko prezentowanego inaczej.

PRYWATNOŚĆ

Najpierw prywatność.
Potem funkcje.

Podstawowy template FamilySyncKids++ działa lokalnie w przeglądarce. Nie wymaga konta, zewnętrznej bazy danych ani przesyłania informacji o dziecku do naszego serwera.

🔒 dane lokalne w przeglądarce 📦 eksport / import JSON 🚫 brak trackerów reklamowych 🧼 repo bez danych realnej rodziny
Ważne

Jeśli korzystasz z template na współdzielonym komputerze, zabezpiecz profil użytkownika systemu. Lokalny zapis nie zastępuje kontroli dostępu do urządzenia.

START

Możesz zacząć bez instalacji.

1Pobierz pusty template

Jeden plik HTML.

2Otwórz w przeglądarce

Chrome, Edge, Firefox lub Safari.

3Wpisz nick dziecka

I nazwę rodzica.

4Dodaj własne elementy

Rutyny, zadania, szkołę i resztę.

FAQ

Najczęstsze pytania.

Czy trzeba zakładać konto?

Nie. Pusty template działa jako lokalny plik HTML.

Czy dane trafiają do chmury?

Nie w podstawowej wersji. Są zapisywane lokalnie w przeglądarce użytkownika.

Czy można używać na kilku urządzeniach?

Sam lokalny template nie synchronizuje się automatycznie. Repo zawiera model danych umożliwiający późniejsze podłączenie własnej synchronizacji.

Czy można zrobić kopię zapasową?

Tak. Template ma eksport i import JSON.

Czy dziecko widzi wszystko, co rodzic?

Nie. Model rozdziela widoki Dziecko, Wspólne i Tylko rodzic.

Czy XP jest obowiązkowe?

Nie. To opcjonalny moduł. System może działać bez punktów i nagród.
