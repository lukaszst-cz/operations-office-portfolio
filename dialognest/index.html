Co robi DialogNest?

Najważniejsze jest nie samo „zebranie czatów”, tylko możliwość późniejszego znalezienia informacji i zachowania własnej organizacji niezależnie od tego, z którego asystenta pochodzi rozmowa.

Import wielu źródeł

ChatGPT, Claude, Gemini, Copilot, JSON, CSV, Markdown, TXT oraz lokalne ZIP/TGZ.

Wyszukiwanie

Pełnotekstowe filtrowanie, operatory, zapisane wyszukiwania oraz opcjonalne lokalne wyszukiwanie semantyczne.

Projekty i tagi

Rozmowy można grupować, oznaczać jako ulubione i porządkować bez zmiany oryginalnych eksportów.

Recovery

Cofanie ostatniego importu, kosz, recovery snapshots oraz bezpieczne przywracanie zmian.

Szyfrowane kopie

Backup .dnvault tworzony lokalnie z weryfikacją integralności przed odtworzeniem.

Desktop + PWA

Natywna aplikacja Windows w Tauri oraz instalowalna PWA korzystają z tego samego modelu lokalnego archiwum.

Można sprawdzić bez własnych rozmów

1Uruchom

DialogNest otwiera lokalne archiwum bez konta i bez zewnętrznej bazy.

2Try safe demo

Cztery fikcyjne rozmowy pokazują wyszukiwanie, źródła, projekty i tagi.

3Importuj

Dopiero gdy chcesz, dodajesz własny eksport z wybranego asystenta.

4Zrób backup

Po weryfikacji archiwum możesz utworzyć szyfrowaną kopię i zachować ją osobno.

Local-first naprawdę znaczy lokalnie

Rozmowy są przechowywane w lokalnym IndexedDB. Importy są analizowane na urządzeniu. Semantyczne wyszukiwanie jest opcjonalne; model może zostać pobrany z publicznego hosta, ale treść rozmów nie jest wysyłana do zewnętrznego API embeddingowego.
