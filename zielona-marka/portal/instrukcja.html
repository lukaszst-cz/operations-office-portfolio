Jak korzystać z PrintFlow Portal

Instrukcja dotyczy publicznej wersji demonstracyjnej. Można ją otworzyć i zainstalować jak aplikację na telefonie albo uruchomić lokalną kopię kodu do nauki i testów.

Otwórz portalOpis projektu

Najprościej

Otwórz stronę na telefonie. Nie potrzebujesz Google Play ani App Store.

1. UŻYTKOWNIK PORTALU

Instalacja na telefonie i komputerze

Android

  1. Otwórz PrintFlow Portal w Chrome.
  2. Wybierz menu ⋮.
  3. Wybierz „Zainstaluj aplikację” albo „Dodaj do ekranu głównego”.
  4. Otwieraj portal z ikony PrintFlow Portal.

iPhone i iPad

  1. Otwórz PrintFlow Portal w Safari.
  2. Wybierz przycisk „Udostępnij”.
  3. Wybierz „Do ekranu początkowego”.
  4. Wybierz „Dodaj”, a następnie uruchamiaj z ikony.

Komputer

  1. Otwórz portal w Chrome lub Edge.
  2. Jeżeli przeglądarka wyświetli ikonę instalacji w pasku adresu, wybierz ją.
  3. W innym przypadku korzystaj normalnie w przeglądarce.

Test statusu

  1. Wejdź do „Strefy klienta”.
  2. Wpisz kod ZM-2024-018.
  3. Sprawdź etap, termin, zaliczkę oraz dostawę.

2. WERSJA LOKALNA DLA NAUKI

Uruchomienie PWA na własnym komputerze

  1. Pobierz kod źródłowy ZIP i rozpakuj archiwum.
  2. Przejdź do katalogu zielona-marka/portal.
  3. Uruchom prosty serwer lokalny przez Python.
  4. Otwórz wskazany adres w przeglądarce.
cd zielona-marka/portal python -m http.server 8080 # następnie otwórz http://127.0.0.1:8080

Do uruchomienia samej aplikacji PWA nie są potrzebne dodatkowe biblioteki. Dane demonstracyjne są w pliku app.js. Zmiany wykonane w panelu są przechowywane tylko w pamięci przeglądarki (localStorage).

3. PROJEKT PYTHON

Uruchomienie PrintFlow Control Center lokalnie

Osobny projekt Python pokazuje serwer, API, SQLite, JSON i testy automatyczne. Jest to rozwinięcie portalu o logikę procesu po stronie aplikacji.

cd printflow-control-center python app.py # aplikacja lokalna http://127.0.0.1:8010 # testy automatyczne python -m unittest discover -s tests -v

Projekt korzysta ze standardowej biblioteki Pythona, nie wymaga instalowania zewnętrznych pakietów.

4. WŁASNA KOPIA DLA FIRMY

Co należy przygotować przed użyciem z prawdziwymi klientami

Nie używaj publicznej wersji demonstracyjnej do obsługi prawdziwych zleceń ani danych osobowych.

Publiczna PWA ma syntetyczne dane i lokalne zapisy. Nie zapewnia kont użytkowników, centralnej bazy danych ani produkcyjnych uprawnień.

  1. Zdefiniuj role, statusy i dane, które klient ma widzieć.
  2. Przygotuj serwer aplikacyjny, bezpieczne API i bazę danych.
  3. Dodaj logowanie, uprawnienia, HTTPS, kopie zapasowe i historię zmian.
  4. Wprowadź zasady RODO, retencję danych oraz procedury obsługi incydentów.
  5. Przetestuj proces na ograniczonej grupie użytkowników przed pełnym wdrożeniem.

5. PUBLIKACJA WŁASNEJ WERSJI PWA

Prosty scenariusz techniczny

  1. Utwórz własne repozytorium GitHub i skopiuj pliki portalu.
  2. Dostosuj nazwę, ikonę, kolory, etapy oraz dane demonstracyjne.
  3. Włącz GitHub Pages w ustawieniach repozytorium.
  4. Otwórz nowy adres w telefonie i zainstaluj aplikację z przeglądarki.

Ten wariant jest właściwy dla strony demonstracyjnej lub wewnętrznego prototypu. Dla systemu obsługującego rzeczywistych klientów potrzebny jest bezpieczny backend opisany w poprzednim punkcie.
