# AUTO NAPRAWA, prezentacja dla klienta

## Jeden link do wysłania

https://lukaszst-cz.github.io/operations-office-portfolio/auto-naprawa-preview/

Strona jest publiczna. Klient nie potrzebuje konta GitHub ani logowania.

## Proponowana kolejność prezentacji

1. Strona główna, oferta, sposób działania i korzyści dla warsztatu.
2. Portal klienta, sprawdzanie statusu naprawy i informacji o zleceniu.
3. Panel zarządzania, pełny widok kierownika, zlecenia, KPI, wartości i marże.
4. Faktury i KSeF, demonstracyjny proces wystawiania i weryfikacji dokumentu.

## Ważna informacja

Projekt jest wersją demonstracyjną przygotowaną do prezentacji klientowi. Dane są przykładowe i zanonimizowane, a integracja KSeF jest symulacją. Wersja produkcyjna wymaga danych warsztatu, logo, domeny, zabezpieczonego zaplecza, bazy danych, kont użytkowników i właściwej integracji z KSeF.
