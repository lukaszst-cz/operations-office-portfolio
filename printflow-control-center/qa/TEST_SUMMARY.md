# Podsumowanie testów, PrintFlow Control Center

## Zakres wydania portfolio QA

- 20 automatycznych testów warstwy biznesowej, SQLite, API i bezpieczeństwa ścieżek;
- 16 udokumentowanych przypadków testowych, w tym pozytywne, negatywne i eksploracyjne;
- macierz ryzyka z priorytetami P1–P3;
- checklista smoke, regresji procesu i interfejsu;
- cztery przykładowe raporty defektów wraz ze statusem i rekomendacją;
- osobna tymczasowa baza danych dla każdego testu.
- macierz śledzenia wymagań oraz bramki jakości GO/NO-GO;
- automatyczne uruchamianie kontroli w GitHub Actions.

## Kryterium decyzji

Wydanie portfolio może otrzymać status **GO**, jeśli wszystkie testy automatyczne przejdą, przypadki P1 nie wykażą regresji, a ograniczenie demonstracyjnego wyboru ról pozostanie jawnie opisane. Projekt nie powinien być przedstawiany jako system produkcyjny ani jako realny mechanizm autoryzacji.

## Dowód kompetencji

Projekt potwierdza praktykę na poziomie mocnego mida w: analizie wymagań, testach funkcjonalnych i regresyjnych, projektowaniu przypadków testowych, testach API i SQL/SQLite, analizie ryzyka, śledzeniu pokrycia, dokumentowaniu defektów, pracy z JSON, automatyzacji w Pythonie oraz definiowaniu bramek CI.
